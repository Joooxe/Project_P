Чтобы запустить на windows достаточно запустить out\build\x64-release\Project_P\Project_P.exe (достаточно иметь в папке с exe-шником папку Resources)
На Linux пока только из среды:
Файлы библиотеки SFML скачать можно с офф. сайта https://www.sfml-dev.org/download/sfml/2.6.1/
И закинуть папку lib вместе с папками include, Project_P, etc... и папку SFML в includes.
